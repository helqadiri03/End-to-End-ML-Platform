Model Download

Learn how to download and use pre-trained models from our platform.

Quick Start

Download a pre-trained model with just a few lines of code:

from nextdata.models import ModelDownloader

downloader = ModelDownloader()
model = downloader.download('xgboost-classifier-v1')

Download Process

1

Choose Model

Select a model from our model registry.

# List available models
from nextdata.models import list_models

available_models = list_models()
print(available_models)
2

Download Model

Download the model and its configurations.

# Download model with specific version
model = downloader.download(
    model_name='xgboost-classifier',
    version='1.0.0',
    include_weights=True
)
3

Load Model

Load the downloaded model into memory.

# Load model from file
from nextdata.models import load_model

model = load_model('path/to/downloaded/model.pkl')
model.summary()
4

Verify Model

Verify the model's integrity and functionality.

# Run basic model verification
from nextdata.validation import verify_model

status = verify_model(model)
print(status.checks_passed)
